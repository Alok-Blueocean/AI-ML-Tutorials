# Videos — Module 01: Introduction and Learning Path

These videos orient you to what MLOps and LLMOps are, how they differ, and how the overall field is structured before you dive into the 26-module course. They are chosen to complement (not duplicate) the written orientation chapter: use them for the "hear it explained a different way" effect, not as a replacement for reading.

---

### 1. MLOps Zoomcamp — Module 1: Introduction (DataTalks.Club)
- **Creator/Channel:** DataTalksClub (YouTube playlist: "MLOps Zoomcamp")
- **Playlist URL:** https://www.youtube.com/playlist?list=PL3MmuxUbc_hIUISrluw_A7wDSmfOhErJK
- **Difficulty:** Beginner
- **Why it's worth watching:** This is the introductory lecture of the most widely used free, structured, self-paced MLOps course on the internet. It frames the ML lifecycle (design → train → operate) that the rest of this textbook's roadmap follows, and it is taught by practitioners who built the course specifically to bridge data-scientist and engineer skill sets — the exact audience gap this module addresses.
- **Complements:** The "what is MLOps and how does it differ from DevOps" section of this module, and previews concepts expanded in Module 02 (CI/CD) and Module 13 (experiment tracking with MLflow, which the Zoomcamp also uses).
- **Rating:** ★★★★★

### 2. Large Language Model Operations (LLMOps) Explained
- **Creator/Channel:** IBM Technology
- **URL:** https://www.youtube.com/watch?v=cvPEiPt7HXo
- **Difficulty:** Beginner
- **Why it's worth watching:** A concise, vendor-neutral-in-substance explanation of what changes when you move from operating traditional ML models to operating LLM-based applications — prompt versioning, retrieval, evaluation-by-model, and cost/latency concerns that don't exist in classic MLOps. IBM Technology's "Techsplainer" series is aimed squarely at engineers who already know software/DevOps basics, matching this course's assumed background.
- **Complements:** The MLOps-vs-LLMOps comparison section of this module; sets up why Modules 07–18 (prompt engineering through agentic tracing) exist as a distinct track from Modules 02–06 and 19–22 (classical MLOps track).
- **Rating:** ★★★★☆

### 4. Full Stack LLM Bootcamp — Course Introduction / LLMOps Lecture
- **Creator/Channel:** The Full Stack (fullstackdeeplearning.com), YouTube channel `@The_Full_Stack`
- **Playlist URL:** https://www.youtube.com/playlist?list=PLj1hYPR-MyXy5nyZv9M9QGcl5KntUCirz

- **Why it's worth watching:** Taught by the UC Berkeley PhD team behind Full Stack Deep Learning, this bootcamp was one of the first to systematically define what "LLMOps" means as a discipline distinct from MLOps — covering prompt engineering, application architecture, and deployment concerns for LLM apps. It is a useful preview of the arc this entire course will walk through in far more depth (Modules 07–18).
