# GitHub Repositories — Module 01: Introduction and Learning Path

Repositories that map to the whole course's scope and give you a sense of the field's breadth before you start Module 02. Popularity tiers are described qualitatively rather than with a fabricated live star count (counts change daily and were cross-checked via search rather than guessed).

---

### 1. DataTalksClub/mlops-zoomcamp
- **URL:** https://github.com/DataTalksClub/mlops-zoomcamp
- **Purpose:** Full open-source curriculum (readings, homeworks, and a linked YouTube playlist) for a free, self-paced MLOps course covering experiment tracking, orchestration, deployment, and monitoring.
- **Popularity tier:** Very popular / widely adopted — one of the most-starred MLOps course repositories on GitHub (roughly in the 12,000–14,000-star range at last check), with an active community and multiple completed cohorts.
- **Why it matters:** It's the closest existing free curriculum to this course's classical-MLOps track (Modules 02–06, 13, 19–22, 25), so it's a useful reference implementation and cross-check as you work through those modules.
- **Relation to this module:** Referenced directly in the videos and provides a template for "how a structured, module-by-module MLOps course is organized" — useful context for understanding why this 26-module course sequences things the way it does.

---

### 2. GokuMohandas/Made-With-ML
- **URL:** https://github.com/GokuMohandas/Made-With-ML
- **Purpose:** An open, project-based course teaching how to design, develop, deploy, and iterate on production-grade ML applications — foundations through MLOps (testing, reproducibility, serving, monitoring, data engineering).
- **Popularity tier:** Very popular / widely adopted — one of the highest-starred MLOps learning repositories on GitHub (roughly in the 40,000+-star range at last check).
- **Why it matters:** Demonstrates the "experimentation to production" narrative arc this course also follows, with real, runnable code rather than slides — a good hands-on companion once you reach the Docker/Kubernetes/serving modules (05, 06, 21).
- **Relation to this module:** A concrete existence proof of the skills this course aims to build; useful to skim now to calibrate your current skill level against the self-assessment checklist in this module.

---

### 3. chiphuyen/aie-book
- **URL:** https://github.com/chiphuyen/aie-book
- **Purpose:** Official supporting repository for Chip Huyen's book *AI Engineering* (2025) — resources, code pointers, and reference material for building applications on foundation models.
- **Popularity tier:** Popular and actively maintained, tied to one of the best-selling and most-read AI engineering books of 2025.
- **Why it matters:** Direct companion to the LLMOps track (Modules 07–18); useful as a living reference that gets updated as tooling evolves faster than the printed book can.
- **Relation to this module:** Ties directly to the book recommendation in `books.md`; a good bookmark for later modules covering evaluation, RAG, and agents.

---

### 4. SylphAI-Inc/LLM-engineer-handbook
- **URL:** https://github.com/SylphAI-Inc/llm-engineer-handbook
- **Purpose:** A curated list of Large Language Model resources spanning model training, serving, fine-tuning, and building LLM applications — companion material associated with the *LLM Engineer's Handbook* book community.
- **Popularity tier:** Popular curated-list repository within the LLMOps space.
- **Why it matters:** Functions as a living "awesome list" for the LLM half of this course; useful to bookmark and revisit as you reach Modules 15–18 and 21 (RAG, agents, tracing, serving).
- **Relation to this module:** Gives a bird's-eye view of the LLMOps tool landscape that this whole course will walk through systematically, module by module.

---

### 5. kelvins/awesome-mlops
- **URL:** https://github.com/kelvins/awesome-mlops
- **Purpose:** A curated list of MLOps tools and frameworks organized by category (data versioning, experiment tracking, model serving, orchestration, monitoring, feature stores, and more).
- **Popularity tier:** Very popular / widely adopted — one of the most referenced "awesome list" repositories in the MLOps space.
- **Why it matters:** This single list roughly enumerates the tool categories that Modules 03, 13, 16, 20, 21, and 22 each cover in depth (registries, vector DBs, orchestrators, servers, feature stores) — a helpful map before diving into any one of them.
- **Relation to this module:** Use it now to get a categorized overview of "everything MLOps touches" before the course breaks each category into its own deep-dive module.

---

### 6. roadmap.sh (MLOps roadmap)
- **URL:** https://roadmap.sh/mlops (interactive) — backing project: https://github.com/kamranahmedse/developer-roadmap
- **Purpose:** A community-maintained, interactive step-by-step roadmap for learning MLOps — programming fundamentals, version control, cloud platforms, containerization, ML fundamentals, data engineering, and core MLOps components (CI/CD, orchestration, experiment tracking, model registries, feature stores).
- **Popularity tier:** Extremely popular — the parent `developer-roadmap` project is one of the most-starred educational repositories on GitHub overall (widely reported in the hundreds of thousands of stars).
- **Why it matters:** Gives a visual, checkable "you are here" map of the broader field that complements the 26-module table in this chapter — useful for cross-referencing topics this course covers against the wider MLOps skill landscape.
- **Relation to this module:** A good secondary sanity-check on this course's own roadmap table — if a topic on roadmap.sh isn't covered anywhere in the 26 modules, that's worth noting as a gap to research independently.

---

## How to use this list
Skim (don't clone-and-run) all six now — the goal at this stage is a mental map of the ecosystem, not hands-on practice. You'll return to #1 and #2 for hands-on exercises starting around Module 05, and to #3–#6 as reference material throughout the LLMOps half of the course.
